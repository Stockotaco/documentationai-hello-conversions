## Quick Setup
<Steps>
  <Step title="Copy your script">
    ````js
    // In the Hello Conversions dashboard
dashboard.mythicdata.com → Copy Script
    ````
  </Step>
  <Step title="Install in GHL funnel">
    - Open GHL > Funnels > Edit Funnel
    - Go to Settings > Tracking Code
    ````html
    Paste script before </head>
    ````
  </Step>
  <Step title="Save & test">
    - Save funnel
    - Open in browser & submit a test form
    - Check email or dashboard for tracked conversion
  </Step>
</Steps>
