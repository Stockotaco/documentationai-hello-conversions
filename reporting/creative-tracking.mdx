**Reporting → Meta Ads → Tracking** is the **Tracking Audit**: of the creatives spending money, which are tagged well enough for the click to be attributable when it lands? It needs the [Meta Ads source](/connect/sources/meta-ads) connected, and covers 7, 30 or 90 days ending yesterday.

## What it checks

One row per creative that spent money in the range, sorted by spend:

| Column | What it means |
| --- | --- |
| **Creative** | Creative name, or the creative ID when it has no name |
| **Landing Page** | The destination URL resolved from the creative — shown as its hostname, and linked. Red **Missing** when the creative carries no destination URL at all |
| **Source** | Whether the creative's URL parameters contain `utm_source` |
| **Medium** | Whether they contain `utm_medium` |
| **Campaign** | Whether they contain `utm_campaign` |
| **Content** | Whether they contain `utm_content` |
| **Spend** | Spend on that creative in the range |

The UTM checks are case-insensitive presence tests on the creative's **URL parameters** field in Meta. They do **not** validate that a value is correct or non-empty — `utm_source=` with nothing after it shows a green tick.

## The four summary cards

| Card | What it counts |
| --- | --- |
| **Total Creatives** | Every creative with spend in the range |
| **Missing UTMs** | Creatives with **none** of source, medium or campaign |
| **Missing Landing Pages** | Creatives with no destination URL |
| **Spend Without Tracking** | Total spend on the creatives counted in Missing UTMs |

`utm_content` is shown in the table but counted by neither the card nor the Issues filter.

## Reading the table

| View filter | Shows |
| --- | --- |
| **All** | Every spending creative |
| **Issues** | Missing any of source, medium, campaign, or a landing page |
| **Valid** | Has all three of those UTMs *and* a landing page |

Rows with an issue **and** more than $100 of spend are tinted red and carry an amber warning triangle. Sort by spend and work down. Every failure is fixed in Meta Ads Manager, at ad level, in the **URL parameters** field — and the same creative may be used by several ads, each needing the fix.

## When the audit looks wrong

| Symptom | Cause |
| --- | --- |
| Table is empty | No creative spent in the range, or the first Meta sync hasn't finished |
| A creative you fixed still shows red | The fix hasn't synced yet — sync is daily at 02:00 UTC, plus a 30-minute result cache |
| A tagged creative shows as untagged | The parameters were appended to the website URL rather than entered in the URL parameters field |
| Missing UTMs card is lower than the Issues row count | The card counts creatives with *no* UTM at all; Issues counts any missing one, so a creative with only `utm_source` is in Issues but not on the card |
| Landing page shows only a hostname | Only the hostname is displayed; the link itself goes to the full URL |
| A creative appears here but not in the Creatives grid | The two use the same source data, but the Creatives grid paginates and can be filtered by format or verdict |
