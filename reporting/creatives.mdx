**Reporting → Meta Ads → Creatives** ranks every ad creative that spent money in the selected period, with a recommended action on each. It needs the [Meta Ads source](/connect/sources/meta-ads) connected.

## What counts as a creative

A row is one **Meta ad creative**, not one ad: five ads across three ad sets using the same creative are one row, summing all five. The campaign column can therefore list several campaigns, and creatives with no spend in the range never appear.

Format is inferred from the creative's structure, in order: carousel child attachments make it a **Carousel**, more than one image in a dynamic asset feed a **DCA Carousel**, a video object or video ID a **Video**, anything else a **Single Image**.

## The objective decides what "a conversion" means

The **objective** is set per project on the Meta Ads row of the Sources screen, defaulting to Purchases; the header dropdown overrides it for the current view without changing the saved default.

| Objective | Counts as a conversion | Cost-per label |
| --- | --- | --- |
| Purchases | `purchase` | CPA |
| Leads | `lead` | CPL |
| Registrations | `complete_registration` | Cost/Reg |
| Add to Carts | `add_to_cart` | Cost/ATC |
| Checkouts | `initiate_checkout` | Cost/Checkout |
| Content Views | `view_content` | Cost/View |
| Contacts | `contact` | Cost/Contact |
| Subscriptions | `subscribe` | Cost/Sub |
| Trial Starts | `start_trial` | Cost/Trial |

**ROAS only exists for Purchases.** Every other objective leaves the column blank and drops it from sorting, from the verdict score, and from the charts on [Frameworks](/reporting/frameworks).

## What each metric measures

| Metric | How it is calculated | Notes |
| --- | --- | --- |
| **Spend** | Meta's daily ad-level spend, summed across every ad using the creative | The one number that is unambiguously Meta's |
| **Conversions** (Purchases, Leads, …) | Meta's reported result count for the selected objective | Meta's attribution, Meta's windows — see below |
| **ROAS** | Meta's own purchase return on ad spend for the creative, over the range | Purchases objective only |
| **CPA / CPL / cost-per** | Spend ÷ conversions | Shown as `--` when the creative has zero conversions, not as `$0` |
| **CTR** | Clicks ÷ impressions × 100 | Meta's link-agnostic click count |
| **CPC** | Spend ÷ clicks | |
| **CPM** | Spend ÷ impressions × 1000 | In the creative detail view |
| **Hook rate** | 3-second video views ÷ impressions × 100 | Video creatives only; replaces CTR on video cards |

Conversion counts arrive from Meta already attributed: where Meta gives a plain total for a result type that total is used, otherwise the count falls back to 7-day-click plus 1-day-view. These are Meta's numbers, not what your [conversion tracking](/conversion-tracking/how-delivery-works) delivered or what the Revenue reports show landing in the CRM.

## Scale, Chill and Kill

Each creative's verdict is relative to the creatives **currently in view**. ROAS, cost-per, CTR and (for video) hook rate each become a z-score against that set — cost-per inverted so cheaper scores higher, capped at ±3 so one outlier can't dominate — combined by fixed weights, then multiplied by a **spend factor** that dampens creatives with too little spend to judge.

| | ROAS | Cost-per | CTR | Hook |
| --- | :---: | :---: | :---: | :---: |
| Purchases, video | 0.40 | 0.35 | 0.15 | 0.10 |
| Purchases, non-video | 0.45 | 0.40 | 0.15 | — |
| Other objectives, video | — | 0.50 | 0.35 | 0.15 |
| Other objectives, non-video | — | 0.55 | 0.45 | — |

| Composite score | Verdict |
| --- | --- |
| 1.0 or higher | **Scale** |
| −0.8 or lower | **Kill** |
| Anything between | **Chill** |
| *Fewer than 3 creatives in view* | **Chill** for everything |

**Confidence** comes from how far the creative sits from average and how much it spent, capped at 100. Each creative also carries a data-sufficiency rating: **low** below a quarter of the average spend (floor $10), **medium** below half (floor $20), **high** above that.

<Callout kind="alert">
  Because the comparison set is whatever is on screen, **changing the date range or the format filter changes the verdicts** — a creative can be Scale in a 7-day view and Kill in a 90-day view without changing at all. Say which range you were looking at when you tell a client to kill an ad.
</Callout>

## How the data refreshes

| Stage | Timing |
| --- | --- |
| Meta Ads → Hello Conversions | Airbyte sync, **daily at 02:00 UTC** (plus one immediately on connect) |
| Creative images and thumbnails | Copied into Hello Conversions storage after each successful sync |
| Report results | Cached for **15 minutes** per project, date range and filter combination |

**Today is never included** — the end of the range is clamped to yesterday in the project's timezone, because Meta's same-day numbers are incomplete. Platform admins get a **Clear cache** button, which drops the 15-minute cache but does not pull new data from Meta.

## When a number looks wrong

| Symptom | Most likely cause |
| --- | --- |
| Every conversion, cost-per and ROAS is zero | Wrong objective for the account — a lead-gen account left on the default Purchases never records `purchase` results. Check the Meta Ads source row first |
| ROAS column missing entirely | Objective is not Purchases. Expected |
| Report is completely empty | No spend in the range, or the first Meta sync hasn't finished |
| A creative you know is running isn't listed | It spent nothing in the range, or its spend landed after the last daily sync |
| Yesterday's spend missing | The 02:00 UTC sync hasn't run since that spend was recorded |
| Numbers changed since this morning | Meta revised its own attribution, or the 15-minute cache expired |
| Verdicts flipped between two views | Different date range or format filter — the comparison set changed |
| Cost-per shows `--` | Zero conversions. Dividing by zero would be worse |
| One creative shows several campaign names | It genuinely ran in all of them |
| A blank thumbnail tile | The creative arrived after the last sync, or its media failed to copy. Metrics are still correct |
| Meta Ads Manager shows different totals | Different attribution window or date range in Ads Manager, or you're comparing an ad-level number against a creative-level total |

For quadrants, fatigue curves and the campaign-by-format matrix see [Frameworks](/reporting/frameworks); for whether creatives are tagged well enough to attribute at all, see [Tracking](/reporting/creative-tracking).
