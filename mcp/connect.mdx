---
title: Connect a Client
description: Point Claude Code, Cursor, Claude Desktop or any MCP-capable client at the Hello Conversions MCP server, with a project key or an organization key.
---

The MCP server is hosted by Hello Conversions — nothing to install, nothing to run locally. The address is the same for everyone; the API key you send with it is what makes it your project.

```
https://mcp.helloconversions.com/mcp
```

<Steps>
  <Step title="Open the MCP API Keys screen" icon="key-round">

    In the project you want the client to read, go to **Settings → Developer → MCP API Keys**. It lists existing keys and, below them, a **Connect via MCP** panel with ready-made snippets.

    <Callout kind="note">
      **Generate Key** and **Revoke** appear only for the project's owner. If you can see the key list but not those buttons, ask the owner to mint the key.
    </Callout>

  </Step>

  <Step title="Generate a key" icon="plus">

    Click **Generate Key**, name it after the client that will hold it, and choose whether it is read-only — the default, and the right choice for anything that only asks questions.

    Copy the key from the banner before you navigate away: only its first eight characters are stored, so it is never shown again. Scoping, expiry and revocation are covered in [Authentication](/mcp/authentication).

    <Callout kind="tip">
      While the new key is still on screen, the snippets below it are filled in with the real key. Once you dismiss the banner they fall back to a `YOUR_API_KEY` placeholder you substitute yourself.
    </Callout>

  </Step>

  <Step title="Paste the configuration into your client" icon="plug">

    Replace `YOUR_API_KEY` with the key you copied.

    <Tabs>
      <Tab title="Claude Code">

        ```bash
        claude mcp add --transport http hello-conversions "https://mcp.helloconversions.com/mcp?token=YOUR_API_KEY"
        ```

      </Tab>

      <Tab title="Cursor">

        The **Cursor** tab of the **Connect via MCP** panel has an **Add to Cursor** button — it opens Cursor and installs the server with your key in place. If nothing opens, use the **Config (JSON)** tab.

      </Tab>

      <Tab title="Claude Desktop / Web">

        **Settings → Connectors → Add custom connector**, and paste this as the URL:

        ```
        https://mcp.helloconversions.com/mcp?token=YOUR_API_KEY
        ```

      </Tab>

      <Tab title="Config (JSON)">

        For Windsurf and other clients that read a config file, add this to your `.mcp.json`:

        ```json
        {
          "mcpServers": {
            "hello-conversions": {
              "url": "https://mcp.helloconversions.com/mcp?token=YOUR_API_KEY"
            }
          }
        }
        ```

      </Tab>
    </Tabs>

  </Step>

  <Step title="Check it works" icon="circle-check">

    Ask the client something verifiable — "list the tables you can see". Then open **Settings → Developer → MCP Usage**: the call appears in **Recent Calls** tagged with the key that made it, which confirms the client reached the project you meant. Allow up to a minute — see [Usage and limits](/mcp/usage-limits).

  </Step>
</Steps>

## Connecting with an organization key

An [organization key](/mcp/authentication) reaches every project you own. There are two forms:

| URL | What the client sees |
| --- | --- |
| `https://mcp.helloconversions.com/mcp` | `list_projects` plus every project tool. Each project tool takes a required `project_id` from `list_projects`. No resources or prompts. |
| `https://mcp.helloconversions.com/mcp/<project id>` | That project's full toolset, resources and prompts, exactly as a project key would see it. Tools take no `project_id`. |

Use the bare `/mcp` if you switch between client accounts in one AI client. The client reads `list_projects`, then names the project on every call:

```bash
claude mcp add --transport http hello-conversions "https://mcp.helloconversions.com/mcp?token=YOUR_ORG_KEY"
```

Use `/mcp/<project id>` to lock a client tool to one account:

```bash
claude mcp add --transport http hello-conversions "https://mcp.helloconversions.com/mcp/PROJECT_ID?token=YOUR_ORG_KEY"
```

<Callout kind="note">
  There is deliberately no "switch project" tool. At the bare `/mcp` every call names its project, and on `/mcp/<project id>` the client stays on that project for the whole session, so no call runs against a project it didn't name.
</Callout>

## Sending the key as a header

The snippets put the key in the URL because most clients only let you configure a URL. If yours can set headers, drop the `?token=` and send:

```
Authorization: Bearer YOUR_API_KEY
```

The server reads the `Authorization` header first and falls back to the `token` query parameter.

<Callout kind="warning">
  A key in a URL is still a password — it lands in the client's config file, and anything that logs URLs logs it. Never paste a connection URL into a shared doc, ticket or chat channel. Mint one key per person and machine so a leak can be revoked on its own.
</Callout>

## If the connection fails

| What you see | What it means |
| --- | --- |
| "Invalid or missing API key" (HTTP 401) | The key is wrong, expired or revoked. Check the status badge on **MCP API Keys**. |
| Connects, but every tool that changes something is refused | The key is read-only — the default. See [Authentication](/mcp/authentication). |
| Retries forever, or complains about SSE | The client is trying the retired HTTP+SSE transport. This server speaks Streamable HTTP only. |
| "Rate limit exceeded" | Past 100 tool calls in a minute on that key — see [Usage and limits](/mcp/usage-limits). |
| Connects, but returns the wrong project's numbers | On a project key, not possible — it is bound to one project, so the key belongs to a different project than you assumed. Check its prefix against the key list. On an organization key, check the project ID in the URL path, or the `project_id` the client passed. |
| A project tool fails asking for `project_id` | An organization key at the bare `/mcp`. The client must pass a `project_id` from `list_projects`, or connect at `/mcp/<project id>` — see above. |
| No resources or prompts | An organization key at the bare `/mcp`. They are only served at `/mcp/<project id>`. |
| "This API key cannot access that project" (HTTP 403) | The project ID in the path is not in this key's organization, or you put a path on a project key. |
| "This API key cannot access project <id>" | The `project_id` the client passed is not in this key's organization. |
