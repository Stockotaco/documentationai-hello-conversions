## Upgrade Instructions

Follow these steps to update Hello Conversions and apply the latest changes.

<Steps>
  <Step title="Backup Your Config" icon="database">

    Export your current settings from the dashboard.

````bash
# From CLI, if using our SDK
helloconversions config export --file backup.json
````

  </Step>
  <Step title="Update Client" icon="download">

    Install the latest version via your package manager.

````javascript
// npm
npm install helloconversions@latest

// Or yarn
yarn add helloconversions@latest
````

  </Step>
  <Step title="Migrate Endpoints" icon="settings">

    Update any custom scripts to use new v2 endpoints.

    <Callout kind="alert">
      Test in staging before production deployment.
    </Callout>

  </Step>
  <Step title="Verify Tracking" icon="check-circle">

    Monitor the dashboard for `>99%` conversion capture rate.

  </Step>
</Steps>
